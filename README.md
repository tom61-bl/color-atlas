# 色彩志

> 互动色彩美学科普。封面、标签页和页脚都使用书名「色彩志」。

**在线阅读**：https://tom61-bl.github.io/color-atlas/

同一套杂志还有 [光影志](https://tom61-bl.github.io/light-shadow/) 和 [字体志](https://tom61-bl.github.io/font-magazine-v1/)。

## 章节

1. 色彩是什么：屏幕上的加色，以及油墨的减色模拟
2. 色彩三要素
3. 色轮与和谐
4. 色彩与情感
5. 中国传统色
6. 用色例子：四件已进入公有领域的作品，加两张本杂志绘制的示意图

案例图不再使用游戏画面。油画和《千里江山图》的作品本身已进入公有领域，页面上写了这不是美术馆官方扫描。

## 本地运行

```bash
python -m http.server 8000
```

然后打开 http://localhost:8000 。样式在 `css/style.css`，交互在 `js/app.js`。

## 许可

正式许可证还没有单独文件。在补上之前，不要把页面、示意图或对照图片当作可以任意再发布的素材。
